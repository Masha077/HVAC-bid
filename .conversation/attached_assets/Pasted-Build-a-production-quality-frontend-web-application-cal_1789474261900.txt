Build a production-quality frontend web application called:

HVAC Bid Intelligence and Validation System

Short application name / UI brand:

HVAC BIS

This is an AI-powered HVAC contractor bid intelligence, requirement analysis, validation, estimation, and bid-deliverable planning system.

IMPORTANT:
Build the FRONTEND ONLY for now.
Do not create a fake backend.
Do not hardcode fake API responses as if they were real.
